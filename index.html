Case study / 01

Two-Tower Recommendation System

The challenge

Represent users and products in a recommendation model using separate towers and learned embeddings.

The solution

PyTorch architecture with 32-dimensional embeddings, Adam optimizer, and 50 training epochs. Flask exposes recommendation and health-check endpoints; Docker packages the service.

Next iteration

Expand offline ranking evaluation, add architecture and response screenshots, and document reproducible benchmarking.

Ranking and retrieval quality metrics are not currently included in the resume.

Case study / 02

Guardrail Detection System

The challenge

Detect roadside guardrails and trees from road images using a two-class object-detection model.

The solution

YOLOv8s trained on a 231-image custom dataset, with Flask inference, experiment tracking, Docker, GitHub Actions, and documented AWS EC2 deployment.

Reported evaluation

0.595mAP@50
0.984Precision
0.400Recall

Reported repository metrics, not independently reproduced. The documented validation and test sets each contain only four images, limiting confidence in generalization.
